# peace: Open Questions

Updated 2026-11-24.

## Open

1. Name. peace is the working title for now.
2. Master tile proportions. How tall is a wall relative to a tile? How wide is a doorway? These must agree across every piece.
3. v1 piece list. Starter set from Chris: walls, domes, doorways, walkways, floors, roofs, ramps. Which others (stairs, pillars, windows, fences) are in v1?
4. Platform expansion. How does the player grow the foundation (click an edge to add a tile, drag out an area, other)? Is there a size limit?
5. Water. Is it only a backdrop, or can pieces be placed on or under it? What happens at the platform edge in walk mode?
6. v1 materials. Proposed: thatch, wood, stone, metal, concrete, glass.
7. Save and share. Autosave, file export and import, screenshots, photo mode as in Castle Builder?
8. Do pieces stack vertically on multiple levels, and how many?
9. Tech. Three.js in the browser is assumed. Confirm, and confirm chunked meshing.
10. Does a piece placed at a nudged position affect which neighbors it snaps to?

## Settled

- Separate game from Castle Builder.
- Square tiles, one grid.
- Blueprint mode: 90 degree rotation, quarter-tile nudge.
- One shape set with swappable materials.
- Stylized look.
- Flight mode and walk mode with simple collision.
